# Reclamos Web — Angular

Aplicación frontend desarrollada con Angular y TypeScript
para la gestión de reclamos del servicio eléctrico.

## Tecnologías

- Angular
- TypeScript
- HTML
- CSS

## Instalación


```bash
npm install
npm start
```

## Funcionalidades

- Formularios de reclamos.
- Carga de archivos adjuntos.
- Ventanas informativas.
- Interfaces para consultas y resarcimientos.
