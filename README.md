# Reclamos Web — Angular

Aplicación frontend desarrollada con Angular y TypeScript
para la gestión de reclamos del servicio eléctrico.

## Tecnologías

- Angular
- TypeScript
- HTML
- CSS

## Instalación


```bash
npm install
npm start
```

## Funcionalidades

- Formularios de reclamos.
- Carga de archivos adjuntos.
- Ventanas informativas.
- Interfaces para consultas y resarcimientos.



## Project Structure

The application follows Angular's component-based architecture.

- `src/app/components/` — Reusable UI components and claim forms.
- `src/app/services/` — Application services.
- `src/app/app-routing.module.ts` — Application routing.
- `src/assets/` — Static resources.

## Development

This project is built with Angular and TypeScript.

To install dependencies:

npm install

To run the development server:

npm start
